## 🚀 Featured Projects

### 1️⃣ Autonomous UAV Monitoring & Maneuvering Platform
> **Stack:** `Django REST` • `MAVLink` • `WebSockets` • `MongoDB` • `Pixhawk`
- **Problem:** Jitter and packet drops during multi-session drone ground control communication.
- **Solution:** Asynchronous WebSocket streaming engine over Django REST Framework interfacing directly with MAVLink C/Python bindings.
- **Impact:** Delivered **sub-100ms packet update latency** with a 15–20% boost in telemetry reliability.

### 2️⃣ Combat Vehicle Tracking Engine
> **Stack:** `Python` • `OpenCV` • `Kalman Filters` • `Kinematic State Estimation`
- **Problem:** Target occlusion and optical feed noise caused lock loss in tactical land vehicle tracking.
- **Solution:** 2D/3D kinematic state estimation pipeline combining Kalman Filtering with OpenCV optical flow.
- **Impact:** Maintained continuous target lock through heavy sensor noise, rapid motion, and camera vibration.

### 3️⃣ Enterprise CRM & Data Automation Platform
> **Stack:** `ASP.NET Core` • `Express.js` • `MySQL` • `RBAC` • `VPS`
- **Problem:** Manual multi-tier administrative workflows created operational bottlenecks.
- **Solution:** Modular Express/.NET Core backend microservices with granular RBAC, JWT validation, and automated webhook pipelines.
- **Impact:** Cut operational overhead by **>90%** while serving thousands of concurrent users at **99.5% uptime**.

### 4️⃣ UK Enterprise & Government Backend Systems
> **Stack:** `ASP.NET Core` • `Azure SQL` • `Blob Storage` • `OAuth2` • `LINQ` • `Azure AD`
- **Problem:** Legacy database queries and unindexed ORM execution degraded high-traffic response times.
- **Solution:** Refactored LINQ query execution, optimized indexing, and modernized Azure App Services.
- **Impact:** Decreased core database load by **25%** under peak volumes exceeding **100,000+ daily transactions**.

## 🚀 Getting Started

Follow these steps to run the portfolio locally on your machine:

### Prerequisites
Make sure you have **Node.js** (v18.0 or higher) and **npm** installed:
```bash
node -v
npm -v
```

### 1. Clone the Repository
```bash
git clone https://github.com/kartheeswaranAR/Portfolio.git
cd Portfolio
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Start Development Server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for Production
```bash
npm run build
```
The optimized production bundle will be generated in the `dist/` directory.
